# Review a Change

Verify the supplied contract digests and exact diff boundary. Read instructions and validation evidence. Check correctness, security, edge cases, scope, architecture, and meaningful tests. Report findings first with stable IDs, file and line evidence, impact, and smallest safe fix. End with `PASS`, `CHANGES_REQUIRED`, or `BLOCKED`; do not modify state.
