# Review a Plan

Verify the plan's issue digest, inspect the published issue and repository evidence, and check scenario references, complete step validation mappings, sequencing, architecture fit, scope control, risks, compatibility, and rollback. Return a plan review with structured stable findings and one supported verdict. Do not edit the plan.
