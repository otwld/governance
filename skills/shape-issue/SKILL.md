# Shape an Issue

Inspect project guidance, relevant code and tests, CI, history, and open and closed issues. Reject duplicates and unresolved material decisions. Draft one structured outcome with evidence, stable requirement and acceptance IDs, scope, constraints, exact validation, readiness, references, and the configured Project IDs when enqueue is requested. Obtain an independent issue `PASS` review. Preview the exact issue through `issue_factory`, require explicit approval of its digest, then publish once. Planning and plan review start during delivery. Treat failed or partial outcomes as blockers and never retry blindly.
