# Set Up a Node Project

Inspect instructions, manifests, lockfiles, workspaces, CI, documentation, and GitHub metadata. Add only evidence-backed governance files. Record the repository, exact install and verify commands, purposeful document paths, optional Project names and node IDs, Status field and option IDs, and squash policy in `.opencode/project.json`. Do not invent scripts, tools, or Project values. Validate with `governance validate-project <root>` and the repository's required check.
