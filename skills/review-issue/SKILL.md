# Review an Issue

Recompute the issue digest and inspect repository and duplicate evidence. Check the structured evidence, stable requirement and scenario IDs, scope, decisions, validation, readiness, and optional configured Project target. Return an issue review with structured stable findings and `PASS`, `CHANGES_REQUIRED`, or `BLOCKED`. A pass has no findings.
