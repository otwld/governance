# Brainstorm an Issue

Frame the user, current workflow, evidence, impact, appetite, and constraints. Ask one consequential question at a time. Generate distinct directions before comparing value, cost, reversibility, risk, and evidence. Pressure-test the preferred direction. Only an explicit user selection produces a concise concept brief for `/issue`; no selection, deferral, evidence request, rejected premise, and do-not-build are valid outcomes. Never publish or implement.
